# Goals

1. Enable retrieval of mails via natural-language prompts.
2. Generate reply drafts grounded in mail context.
3. Drafted replies should match the sender's usual writing style.
4. Answer user questions using the mail corpus as a knowledge base.
5. Preserve user trust by keeping the human in the loop on outbound replies.
6. Keep mail content private — process locally and avoid disclosing sensitive data to external services.
