Replace the current session-based authentication system with JWT-based auth. The existing system stores session tokens in a PostgreSQL sessions table and validates them on every request through the AuthMiddleware. We need to migrate to short-lived JWTs with refresh token rotation, update all API endpoints that read session data, and add token revocation support. There are approximately 40 API endpoints that use the current auth middleware. No tests exist for the auth middleware itself — endpoint tests mock it away.
