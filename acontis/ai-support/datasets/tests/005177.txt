<div>This is more of an FYI, but recently we discovered that the Xenomai project has been supporting a kind of in-between project that has the Xenomai 3 API built on top of the new "dovetail" / EVL kernel model.</div>
<div> </div>
<div>I have been able to build Xenomai from the <code>stable/3.2.x</code>​ branch using the <code>xenomai-dovetail</code>​ repo for kernel 5.15.98, and with a few changes, get <code>atemsys</code>​ to build for it.</div>
<div> </div>
<div>The biggest thing was that the kernel configuration option changed from CONFIG_XENO_COBALT to CONFIG_XENOMAI, and I still had some issues with the #ifdefs and resorted to moving the irq.h include outside, but I think I was fighting a different issue.</div>
<div> </div>
<div>I actually haven't <i>run</i> it yet, but have a pretty good feeling for its chances.</div>
<div> </div>
<div>Out of curiosity, has anyone looked into this at Acontis yet?</div>
