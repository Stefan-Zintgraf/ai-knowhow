### ARTICLE00_BODY
<div>
<p>Hello Support,</p>
<p> </p>
<p>We’ve run into issues where our master reports <i>ERROR: No memory left (0x9811000a)!</i> In the attached file, this happens at Time = 147.682 826</p>
<p> </p>
<p>This happened by having a network running (in GenPreOp) and going into the Edit Topology view. We then did a network scan repeatedly until this error occurred. Attached is an ECC project of the slaves that were connected to the network. Note, no ENI file was downloaded. <b>Do you have any idea why this happens?</b></p>
<p> </p>
<p>Potentially related, I found the below code in EcDevice.cs, which indicates that we can receive EC_E_NOMEMORY for repeated network scans with GenPreOp. <b>Can you elaborate on why this happens?</b> </p>
<p><i> // Set master state to PreOp, so "PortSlaveIds" will be set!<br> if (!IsMasterVersionSmaller("02.07.00.00", true))<br> {<br> if (scanBus &amp;&amp; !rasIsConfigured)<br> {<br> if (!ConfigureMaster(true))<br> {<br> // Retry (without GenPreOp, because we could receive "EC_E_NOMEMORY" for slaves with big PDOs)<br> if (!ConfigureMaster(false))<br> return false;<br> }<br> }<br> }</i></p>
