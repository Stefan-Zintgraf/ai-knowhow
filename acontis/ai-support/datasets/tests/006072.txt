Hi,<div><br></div><div>sorry. This is not just a warning. EC-Engineer is not able to handle multiple devices with same VendorID&amp;ProductCode&amp;RevisionNo. The reason for that is, if you scan your network it is not clear which device to take.</div><div><br></div><div>Why do you think that you need this? </div><div><br></div><div>Normally ESI vendors create theire ESI files compatible between the revisions. You can see the ESI settings of the specific device e.g. on Advanced tab:</div><div><br></div><div>
<img style="max-width:100%;width: 1000px;max-width: 100%;" src="/api/v1/ticket_attachment/6072/32493/135589?view=inline"><br>
</div><div><br></div><div>... they include also older revisions into the same ESI file. So the default behaviour is to delete the old ESI file and replace it with a newer one. </div><div><br></div><div>Best Regards,</div><div>Martin</div><div>
