### ARTICLE00_BODY
<div dir="ltr">Folks,<div> </div>
<div>1. We are experimenting with KEBA Servo One drive with Acontis.</div>
<div>2. Here are my observations while using EC-Engineer with the KEBA ServoOne drive.</div>
<div>- Downloaded the ESI file from the KEBA website and Added the folder to EC-Engineer.</div>
<div>- In the Online Configuration Mode EC-Engineer the following happens:</div>
<div>- Bus scan is successful. 1 slave is detected.</div>
<div>- Master changes state from UNKNOWN-&gt;INIT-&gt;PREOP</div>
<div>- I go to Diagnosis Mode.</div>
<div>- I see that the Master and the Detected Slave are in INIT mode</div>
<div>- I change the state of the Master from INIT-&gt;PRE-OP-&gt;SAFE-OP-&gt;OP</div>
<div>- The slave also follows the same state transition.</div>
<div>- The Motion Mode is ENABLED in the View Dropdown.</div>
<div>- I DO NOT SEE THE MOTION TAB for the Slave.</div>
<div>3. The log file generated by EC-Engineer is attached.</div>

There is no such application started when you connect directly from EC-Engineer. You have to use EcMotionDemo.exe.</div><div>You can start your config with the Motion EMI. Then the script Tab is activated. There you can select how the Demo should be started.</div><div><br></div><div>Best regards,</div><div>Kai Feifel</div><div>
