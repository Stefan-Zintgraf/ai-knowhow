Dear EtherCAT Support

Question about EC-Master(Panasonic Smart Factory Solutions) [CN.40434]

When customer execute the "modprobe atmsys" command, the following error is output.
   modprobe: can't change directory to '4.19.0': No such file or directory

location of atemsys:
   /lib/modules/4.19.142-rt63/kernel/drivers/char/acontis/atemsys.ko

If they create a folder of 4.19.0, copy the files under 4.19.142-rt63 and execute it, the following error will be output.
   atemsys: version magic '4.19.142-rt63 SMP mod_unload ARMv7 p2v8 ' should be '4.19.0 SMP mod_unload ARMv7 p2v8 '
   modprobe: can't load module atemsys (kernel/drivers/char/acontis/atemsys.ko): invalid module format

When they try "modprobe -f atmsys", they get the following error:
   root@rzn1d400-db:~# modprobe -f atemsys
   modprobe: invalid option -- 'f'
   BusyBox v1.24.1 (2021-04-13 02:17:23 UTC) multi-call binary.

   Usage: modprobe [-alrqvsD] MODULE [SYMBOL=VALUE]...

When they try "insmod", they get the following error:
   atemsys: version magic '4.19.142-rt63 SMP mod_unload ARMv7 p2v8 ' should be '4.19.0 SMP mod_unload ARMv7 p2v8 '
   insmod: can't insert '/lib/modules/4.19.0/kernel/drivers/char/acontis/atemsys.ko': invalid module format

Please tell me how to resolve.


Best regards,
Takuya Fujikawa
