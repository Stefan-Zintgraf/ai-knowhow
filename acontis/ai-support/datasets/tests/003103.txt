Dear EtherCAT Support

Question about EC-Master (FANUC) [M81]

About ecatExecJob (eUsrJob_MasterTimer) using DCsync.
I was testing with a network configuration where one JobTask cycle takes about 500us.

- When the EtherCAT communication cycle is set to 1000us
Without DCSync,JobTask was working without fluctuation.However,with DCSync, the JobTask has greatly fluctuation and DCSync's active / deactive was frequently switched.ecatExecJob (eUsrJob_MasterTimer) usually takes 40us, but when this problem occurs, it rarely took 1200-1300us.

- When the EtherCAT communication cycle is set to 2000us
With this setting, even with DCSync, ecatExecJob (eUsrJob_MasterTimer) continued to run on 40us without fluctuation

Is it possible for acontis to guess why ecatExecJob (eUsrJob_MasterTimer) rarely takes a long time?
This could also be a problem with FANUC's application creation.
Please let me know if you can guess as general knowledge(the communication cycle is too short, the network is congested, etc.).

Best regards,
Takuya Fujikawa
