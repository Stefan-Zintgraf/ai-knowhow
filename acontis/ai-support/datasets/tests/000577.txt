<div dir="ltr">Hello all!<div> </div>
<div>There are two issues I've run into recently:</div>
<div> </div>
<div>1. The timeout for ecatScanBus is not used in all subcalls. It looks like it's missing from one of the subcalls, and there are certain scenarios where the thread will lock because of that.</div>
<div> </div>
<div>2. I'm trying to find some way of reading the object dictionary list that is set in an ENI file. The closest I've found is ecatCoeGetODList, which appears to be an async request I can initiate after the device is in OP. I'm looking for what the closest equivalent might be that I can call just after ecatConfigureMaster is called, that I can request synchronously. Does such an API exist/is there an equivalent that will list out names of ENI variables before OP?</div>
