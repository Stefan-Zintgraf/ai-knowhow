Dear EtherCAT Support

*This question is different from "Question about "EC-Master-V3.1-FreeRTOS-ARM_32Bit-Eval" for SHIBAURA MACHINE. [Ticket#706476]".

They are currently checking the operation using the evaluation version below.
    "EC-Master-V3.1-FreeRTOS-ARM_32Bit-Eval"
    "EC-Master-ClassA-AddOn-V3.1-FreeRTOS-ARM_32Bit-Eval"

They are evaluating the ZC702 environment without any changes from the evaluation version.

When you open the following project with the evaluation version you received using Xilinx SDK, the properties of EcMasterDemo_ZC702Rev are "EcMasterDemo_ZC702Rev_properties_NG.png".
    "Workspace\FreeRTOS_Xilinx\EcMasterDemo_ZC702Rev"
    "Workspace\FreeRTOS_Xilinx\ZC702Rev_hw_platform"

 From this state, when you download it with DEBUGGER and start it, the following error will occur.
    "EcMasterDemo_ZC702Rev_properties_NG_Problem_Occurred.png"

If you remove the following selections from this property state, download it with DEBUGGER, and run it, you can run it without any problems.

    ・EcMaster_ps7_cortexa9
    ・emllGEM_ps7_cortexa9
    ・ZC702Rev_hw_platform

The property setting at this time is "EcMasterDemo_ZC702Rev_properties_OK.png".

So here's a question.

Are the property settings in "EcMasterDemo_ZC702Rev_properties_OK.png" correct?

Thank you for your confirmation.
