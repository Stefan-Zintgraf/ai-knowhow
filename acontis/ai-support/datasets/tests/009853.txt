<div>
<p><span lang="EN-US">Dear Support Team</span></p>
<p><span lang="EN-US"><p> </p></span></p>
<p><span lang="EN-US">I received a question from DENSAN.</span></p>
<p><span lang="EN-US"><p> </p></span></p>
<p><span lang="EN-US">An end user with EC-Master V2.7.4.12 installed has contacted them with a question </span></p>
<p><span lang="EN-US">about the return value EC_E_BUSY when executing ecatSetSlaveState.</span></p>
<p><span lang="EN-US"><p> </p></span></p>
<p><span lang="EN-US">In a customer's environment, EC_E_BUSY occurred when a slave was transitioning </span></p>
<p><span lang="EN-US">from INIT-&gt;PREOP-&gt;SAFEOP-&gt;OP using ecatSetSlaveState.</span></p>
<p><span lang="EN-US">After EC_E_BUSY occurred, the slave was in PREOP state.</span></p>
<p><span lang="EN-US"><p> </p></span></p>
<p><span lang="EN-US">However, the occurrence of EC_E_BUSY was only confirmed once,</span></p>
<p><span lang="EN-US">and when ecatSetSlaveState was used on a different day, the state transition to OP was achieved.</span></p>
<p><span lang="EN-US"><p> </p></span></p>
<p><span lang="EN-US">Could you please tell me when this EC_E_BUSY is returned?</span></p>
<p><span lang="EN-US"><p> </p></span></p>
<p><span lang="EN-US">(Kenji)</span></p>
<p><span lang="EN-US">Does this occur when a request to transition to the next status is made when the transition to the requested status has not been completed?</span></p>
<p><span lang="EN-US">However, at that time, I wondered if the first state transition would time out...</span></p>
<p><span lang="EN-US"><p> </p></span></p>
<p><span lang="EN-US"><p> </p></span></p>
<p><span lang="EN-US">Best Regards,</span></p>
<p><span lang="EN-US">Kenji Nakamura</span></p>

Hi Kenji,<div><br></div><div>EC_E_BUSY is returned if another API like emSetSlaveState() or emSetMasterState() was called in parallel and set the slave state again at the end of the current API call:</div><div>
