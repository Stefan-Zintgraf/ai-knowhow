### ARTICLE01_SUBJECT
Duplicate Device ESI file Fehlermeldung

### ARTICLE01_BODY
Hallo Herr Merkel,<div><br></div><div>bei uns sind VendorID, Product Code und Revision Number die unique ID. Wenn die drei Zahlen gleich sind, können wir das so leider nicht verwalten. Für so einen Fall der "Vorkonfiguration" des gleichen Gerätes sind eigentlich SCI Files gedacht. </div><div>Sie könnten dem einen Gerät als Workaround im ESI eine andere Revisionsnummer geben. Dann können Sie im Engineer über Change SubDevice / Slave, die andere Konfiguration wählen. Falls Sie nichts daran konfigurieren möchten, könnten Sie sich dann ein SCI file erstellen, bei diesem die Revision ändern und wieder reinladen. Falls Sie die Konfiguration anpassen müssen, bleibt Ihnen hier eigentlich nur der Workaround über die Revisionsnummer.</div><div><br></div><div>Eventuell wird die andere Konfiguration auch angezeigt, wenn Sie hier "Show hidden Slaves" auswählen. Das kann ich aber ohne Ihr ESI file zu haben, nicht sicher sagen.</div><div><br></div><div>Viele Grüße</div><div>Kai Feifel<br><div data-signature="true" data-signature-id="2">
