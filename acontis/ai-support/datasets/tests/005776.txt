Customer Suggestions for EC-Engineer

### ARTICLE00_BODY
Hi,<div> </div><div>We received a customer suggestion for EC-Engineer that I wanted to pass along and see if this was a useful feature to have in your opinion.</div><div> </div><div>1. The first was for the an additional data point when in Diagnosis mode to show the master offset from the system time (so how well the master is in sync when using DC). The customer indicates that it would be helpful to diagnosis issues with DC during startup and in steady state to see this value quickly in EC-Engineer, perhaps even with a chart showing the value plotted over time.</div><div> </div><div>2. The second suggestion was for a button in EC-Engineer to download the log files including the DCM log file. This way they could save time in going to the controller and getting the log file from there to bring to a Windows PC for analysis. They could leave the master running on the controller and pull the log file off over the network and then analyze them in their Windows PC where EC-Engineer is running.<br><div>
<br>/Jon </div>
