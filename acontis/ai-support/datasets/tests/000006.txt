### ARTICLE00_SUBJECT
Abfragen am EtherCAT-Master

### ARTICLE00_BODY
<div>
<p>Guten Tag</p>
<p> </p>
<p>Ich bin am Überarbeiten des Zugriffs auf den EC-Master (Java-Applikation, Zugriff auf die EC-Master-Library via JNI und C++). Dazu einige Fragen.</p>
<p>Wir verwenden noch den EC-Master 2.9.1.10</p>
<p>Ich habe die beiden Dokumente:</p>
<p>EC-Master EtherCAT® Master Stack Class B, Version 2.9, Edition: 2018-05-28</p>
<p>EC-Master EtherCAT® Master Stack Class A, Version 2.9, Edition: 2018-05-28</p>
<p> </p>
<p>Wir rufen die Methode EC_T_DWORD ecatGetSlaveId (EC_T_WORD wStationAddress) auf. Einmal mit einem short, an anderer Stelle mit einem int. Das scheint funktioniert zu haben!? Was passiert genau beim Aufruf mit dem falschen Typ? Wäre das zulässig? (ich würde das durchgehend auf short korrigieren</p>
<p> </p>
<p>Ich möchte die Version des EtherCAT-Masters von der Library abfragen. Im Handbuch "EC-Master EtherCAT® Master Stack Class B Version 2.9" wird im Kapitel "4.3.27 ecatGetVersion" die Methode angegeben.</p>
<p>Wie viele DWORD werden empfangen und wie sind diese auszuwerten (Major, Minor, usw.)?</p>
<p>Welche Werte kann der Error Code annehmen?</p>
<p>Im EcVersion.h steht #define ATECAT_FILEVERSIONSTR "2.9.1.10\0". Ist das gleichwertig?</p>
<p> </p>
<p>Bei ecatGetBusSlaveInfo (Kapitel 4.6.34) muss wSlaveAddress angegeben werden. bFixedAddressing ist bei unserer Software false (auto-inkrement), die Adresse wird mit 0, -1, -2, usw. abgefragt.</p>
<p>Wo ist beschrieben, wie die Adresse angegeben werden muss? Was bedeuten die Adressen 0, -1, -2, usw.?</p>
<p>(Diese Art der Adresseingabe wird bei uns an verschiedenen anderen Stellen ebenfalls benützt)</p>
<p> </p>
<p>Vielen Dank &amp; freundliche Grüsse</p>
