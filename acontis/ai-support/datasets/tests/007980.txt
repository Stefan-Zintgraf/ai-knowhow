Dear EtherCAT Support

Question about EC-Engineer SDK(Panasonic Industry) [E009]

When the .NET Framework is changed to 4.8 in the following project
(EtherCATSuite, EcView, EcViewControls, EcViewModel, EcViewPlugin, EcViewResources), there is a case that it takes a little bit time to switch the tab.
The procedure is below.
1. Start EtherCATSuite.sln
2. Change the framework to ".Net Framework 4.8" in each project.
3. Execute the build and start debugging.
4. Click the "New Project" on "EtherCAT Suite" dialog.
5. Click the "EtherCAT Dialog" button.
6. Select "Slave_1008" in Project Explorer and click "Advanced Options" tab.
7. Select "EtherCATSuite Master" in Project Explorer.
What is the problem?

Best regards,
Takuya Fujikawa
