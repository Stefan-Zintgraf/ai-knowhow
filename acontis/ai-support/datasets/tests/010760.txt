### ARTICLE02_BODY
Hi Yuichi,<br><br>Issue 1: The Error box "Invalid Value" is from the control itself, this Error box is displayed  as long as the control is not in focus, even selecting the same subindex causes this.<br>Issue 2: This is our code, the code checks if the inserted value is within the range of valid values of the OD Entry, these values come from the ESI.<br>Issue 3: Due to the limitation of Real32 values, it only has <span>7 decimal digits precision, the number 99,999,999 is seen as 1E+08.  </span><br><br>Best regards<div data-signature="true" data-signature-id="2">
