### ARTICLE00_SUBJECT
unclarity about the DCM mode to use for MasterRefClock

### ARTICLE00_BODY
<div>
<p>Hi,</p>
<p> </p>
<p>In the company we are integrating the Acontis Ethercat stack, in order to configure the distributed clock correctly I am looking at how to setup the ENI file in EC-Engineer and which settings should be used for the emDcmConfigure function.</p>
<p> </p>
<p>We are planning to use the ‘MasterRefClock’ where we provide our own hosttime function callback so that the timebase of our system is equal to that used on the ethercat bus.</p>
<p> </p>
<p>When reading the EC-master manual (v3.2) in chapter 2.1.6 it is stated that in order to use the Master Ref Clock mode in the ENI file bus shift time should be enabled, as they share the same cyclic commands.</p>
<p> </p>
<p>If we then open EC-engineer to configure and setup the ENI for Distruted clocks the ‘Distributed Clocks’ tab shows some else and seems to indicate we should select ‘MasterShift’ instead</p>
<p> </p>
<p><img style="max-width:100%;width:9.052in;max-height:5.7187in;width:869px;max-height:549px;" src="/api/v1/ticket_attachment/9031/51093/212453?view=inline"></p>
<p>(Note that also the above tab from EC-engineer does not match the tab as it’s shown in the manual in chapter 1.3.1 ‘Distributed Clocks Master settings (Expert)’)</p>
<p> </p>
<p>Could please explain which mode we should select in EC-Engineer so that we can setup the DCM with emDcmConfigure() to use MasterRefClock with our own hosttime function?</p>
<p> </p>
