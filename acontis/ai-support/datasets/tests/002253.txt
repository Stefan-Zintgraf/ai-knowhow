### ARTICLE01_SUBJECT
[ADLINK] The meaning of debug output message

### ARTICLE01_BODY
<div>Hi Ryan,</div><div><br></div><div>DC slaves "out-of-sync" means that the system time difference read between the reference clock and the DC slaves behind (ESC:0x092C) is above the configured limit. This limit can be set by <span>EC_T_DC_CONFIGURE::</span><span>dwDevLimit.</span>
</div><div>This measurement is part of the "sync window monitoring" enabled by a configured cyclic command BRD 0x92C.</div><div><br></div><div>The current value of 0x3c133 is in ns and means that the system time value of one or some particular slave(s) is about 250us. This is very big.</div><div><br></div><div>I would need the master log file and if possible a Wireshark to understand more.</div><div><br></div><div>Best Regards,</div><div>Cyril<br><br>
