### ARTICLE00_BODY
<div>
<p>Hi Cyril,</p>
<p> </p>
<p>I have new request for you. We need an ability to not send frames if it’s ‘too late’. There are cases when our application stalls inside acontis Tx call for long enough to cause DCM to go out of sync. So we’d better not send frames at all, rather than sending them late.</p>
<p> </p>
<p>Below is the way I modified code in 2.8 (main goal was to make minimal changes) and is for illustration purpose only.</p>
<p> </p>
<ol start="1" type="1">
<li>typedef EC_T_BOOL (*EC_T_LINK_TX_DEADLINE_CB)(EC_T_PVOID pCallerData); </li>
</ol>
<p> </p>
<ol start="2" type="1">
<li>… </li>
</ol>
<p>EC_T_LINK_TX_DEADLINE_CB pfnIsTxDeadlineMet;</p>
<p>EC_T_PVOID pvTxDeadlineContext;</p>
<p>} EC_PACKED(8) EC_T_LINK_FRAMEDESC;</p>
<p> </p>
<ol start="3" type="1">
<li>static EC_T_DWORD EcLinkSendFrame( </li>
</ol>
<p>…</p>
<p>/* if too late to send frame, reset frame's size to 0 - i.e. send frame of 0 size */</p>
<p>EC_T_BOOL bSkip = EC_NULL != pLinkFrameDesc-&gt;pfnIsTxDeadlineMet &amp;&amp; !pLinkFrameDesc-&gt;pfnIsTxDeadlineMet(pLinkFrameDesc-&gt;pvTxDeadlineContext);</p>
<p>if (bSkip)</p>
<p>{</p>
<p>EC_LL_T_TransDescriptor_SET_LENGTH(pPhysDesc, 0U);</p>
<p>}</p>
<p>REGISTER_WRITE(pAdapter-&gt;pbyRegisterBase, I8254X_REGOFFS_TRANSMIT_TDT, pAdapter-&gt;dwTxNextTail);</p>
<p>…</p>
<p>dwRetVal = bSkip ? EC_E_FRAME_LOST : EC_E_NOERROR;</p>
<p>)</p>
<p> </p>
<p>Regards,</p>
<p>Eugene</p>
