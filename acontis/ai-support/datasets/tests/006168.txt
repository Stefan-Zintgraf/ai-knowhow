### ARTICLE00_SUBJECT
DCM Status functions for CEcDcmRefClockBase

### ARTICLE00_BODY
<div>
<p>I am reviewing the changes to MasterRefClock/LinkLayerRefClock in V3.2.1.01 and seeing how many of my customizations can be removed.</p>
<p> </p>
<p>One thing that I noticed was that CEcDcmMasterRefClock implements these 4 status functions:</p>
<p> </p>
<p><span style="color:blue;"> class</span>
<span style="color:#2b91af;">CEcDcmMasterRefClock</span> : <span style="color:blue;">public</span>
<span style="color:#2b91af;">CEcDcmRefClockBase</span></p>
<p>{</p>
<p>...</p>
<p> <span style="color:blue;">virtual</span>
<span style="color:#6f008a;">EC_T_VOID</span> SetStatus(<span style="color:#2b91af;">EC_T_DWORD</span>
<span style="color:gray;">dwStatus</span>) <span style="color:#6f008a;">EC_OVERRIDE</span> { m_dwStatusCode = <span style="color:gray;">dwStatus</span>; }</p>
<p> <span style="color:blue;">virtual</span>
<span style="color:#2b91af;">EC_T_DWORD</span> GetStatus(<span style="color:#2b91af;">EC_T_DWORD</span>* <span style="color:gray;">pdwErrorCode</span>, <span style="color:#2b91af;">EC_T_INT</span>* <span style="color:gray;">pnDiffCur</span>, <span style="color:#2b91af;">EC_T_INT</span>* <span style="color:gray;">pnDiffAvg</span>, <span style="color:#2b91af;">EC_T_INT</span>* <span style="color:gray;">pnDiffMax</span>) <span style="color:#6f008a;">EC_OVERRIDE</span>;</p>
<p> <span style="color:blue;">virtual</span>
<span style="color:#2b91af;">EC_T_DWORD</span> ShowStatus(<span style="color:#6f008a;">EC_T_VOID</span>) <span style="color:#6f008a;">EC_OVERRIDE</span> { <span style="color:blue;">return</span>
<span style="color:#6f008a;">EC_E_NOTSUPPORTED</span>; }</p>
<p> <span style="color:blue;">virtual</span>
<span style="color:#2b91af;">EC_T_DWORD</span> ResetStatus(<span style="color:#6f008a;">EC_T_VOID</span>) <span style="color:#6f008a;">EC_OVERRIDE</span> { <span style="color:blue;">return</span> m_dwStatusCode = <span style="color:#6f008a;">EC_E_NOERROR</span>; }</p>
<p>...</p>
<p>};</p>
<p> </p>
<p>However, they were not added to CEcDcmLinkLayerRefClock. Why is that? It seems like being able to access the current/average/max error is equally useful for LinkLayerRefClock as it is for MasterRefClock, in which case they could be moved to CEcDcmRefClockBase.</p>
<p> </p>
<p>I admit that I do not fully understand the m_dwStatusCode portion of this set of functions, but the current/average/max errors would be very nice to have.</p>
<p> </p>
<p>Thank you.</p>
