### ARTICLE02_BODY
<div>Hi,</div><div><br></div><div>we discussed it now and in the next release we will change the refresh cycle to "normal", so it will refresh in future every:</div><div>local: 400ms</div><div>remote: 1200ms</div><div><br></div><div>the second issue regarding adding DC diagnosis tab:</div><div>We show the DC Diagnosis tab because t<span>he OD value "DC Support" is true. This value is true, because the ESC of the slave has DC support. E.g. like an EK1100 can be used as a reference clock. So, it is correct to show this tab.</span>
</div><div> </div><div>Best Regards,</div><div>Martin</div><div>
