<div>
<p>Bonjour Mr Eyssautier,</p>
<p> </p>
<p>Dans ecatnotification ProcessNotification</p>
<p> </p>
<p>Ne manque-t-il pas les traitements des notifications EC_NOTIFY_RAWCMD_DONE et EC_NOTIFY_RAWCMD_DONE qui sont mises en queue de job, mais non traitée ?</p>
<p> </p>
<p>Dans le code :</p>
<p> </p>
<p>} break;</p>
<p>#ifdef INCLUDE_FOE_SUPPORT</p>
<p>case eMbxTferType_FOE_SEG_DOWNLOAD:</p>
<p>{</p>
<p>EC_T_MBXTFER* pMbxTfer = &amp;(TmpJob.JobData.MbxTferJob);</p>
<p>if (eMbxTferStatus_TferWaitingForContinue == pMbxTfer-&gt;eTferStatus)</p>
<p>{</p>
<p>/* read from file to application's buffer */</p>
<p>m_SegmentedFoeDownload.dwDataLen =</p>
<p>(EC_T_DWORD)OsFread(pMbxTfer-&gt;MbxTferDesc.pbyMbxTferDescData, 1, pMbxTfer-&gt;MbxData.FoE.dwRequestedBytes, (FILE *)m_SegmentedFoeDownload.hFile);</p>
<p> </p>
<p>/* queue application's buffer to be transferred to slave */</p>
<p>emFoeSegmentedDownloadReq(m_dwMasterInstance, pMbxTfer, 0, EC_NULL, 0, 0, 0, 0);</p>
<p>}</p>
<p>} break;</p>
<p>#endif /* INCLUDE_FOE_SUPPORT */</p>
<p> </p>
<p>Si INCLUDE_FOE_SUPPORT est défini, le code ne compile pas, car eMbxTferType_FOE_SEG_DOWNLOAD n’est pas une notification, mais un champ de la notification EC_NOTIFY_MBOXRCV</p>
