Hi Shaun,<div> </div><div>I will check if this large deviation makes sense, but I think it could be possible because CoE is using the mailbox protocol which is acyclic communication. So there is no guarantee when the CoE request and CoE response are sent/received on the network. It depends on the mailbox buffer size and how much bytes are available in the overall frame for when it can execute this transfer.<br><div>

<p>Hi Jon,</p>
<p> </p>
<p>Thank you.</p>
<p> </p>
<p>It ended up being a Linux scheduler issue on a highly loaded system. We are using a Linux RT kernel and our COE thread was being starved out.</p>
<p> </p>
<p>We increased the COE thread priority and used SCHED_FIFO (RT scheduling) and that resolved our immediate issue.</p>
<p> </p>
<p>Thanks for your help!</p>
