### ARTICLE00_SUBJECT
Using 2 EtherCAT bus(es)

### ARTICLE00_BODY
<div>
<p>Hi,</p>
<p>We are using LxWin.</p>
<p>We are contemplating using 2 distinct EtherCAT bus(es) on the same machine (that of course has 2 NICs).</p>
<p>The bus(es) and their HW do not need to be synchronized between themselves. We know that the Data we receive will have the same clock source.</p>
<p> </p>
<ul type="disc">
<li>Is it possible to use the same instance of EC-Master to create 2 EtherCAT bus(es) each on one NIC card?</li>
<li>If not, can we create 2 instances of EC-Master (each will use 1 NIC card)? If so, can these 2 instances co-exist on the same Linux process, or should they be in 2 separate processes?</li>
</ul>
<p>I understand the complexity of thread priority that will come with this idea, but just wanted to explore the possibilities.</p>
<p> </p>
<p>Thanks,</p>
<p>Naji</p>
