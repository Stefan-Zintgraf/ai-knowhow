### ARTICLE00_SUBJECT
[Chieftek]Variable write and Coe read

### ARTICLE00_BODY
<div dir="ltr">Hi,<div>Within OP mode of a slave, an OD (ex. 0x7100:2) we used EcSlaveDiagVariables.WriteValue() to write a value to OD. The value, truly changed if we used EcSlaveDiagVariables.ReadValues() to get OD value back. But when we used EcSlaveDiagCoe.Read(index, subindex,...) to read back the same OD, it becomes no change.</div>
<div>
<br><div>The same OD, EcSlaveDiagVariables.WriteValue() only affected EcSlaveDiagVariables.ReadValue() result. We didn't know why.</div>

### ARTICLE01_BODY
Hi,<div><br></div><div>
<span>some variables were mapped from the slave into the CoE object dictionary. Those values cannot be written via EcSlaveDiagCoe.Write(...). You can read/write they like you did by using </span><span>EcSlaveDiagVariables.ReadValues/WriteValue.</span><br>
</div><div><br></div><div>So, it depends on the slave how he map those variables into CoE OD.</div><div><br></div><div>In may case, I wrote to first analog output of EL4004 on variables tab:</div><div><br></div><div>
