### ARTICLE00_SUBJECT
Question Synchronisation Esclave Distributed Clock

### ARTICLE00_BODY
<div>
<p>Bonjour,</p>
<p> </p>
<p>Nous constatons certaines pertes de trame Ethercat durant des tests en endurance. Nous soupçonnons le système de Distributed Clock (DC) d’en être la cause.</p>
<p> </p>
<p>Actuellement, notre configuration de synchronisation est en Master Shift Mode avec génération de signaux HW SYNC0 (pas de SYNC1). Nous utilisons les paramètres générés par défaut par EC-Engineer (ShiftTime, CycleTime0 etc…).</p>
<p> </p>
<p>En consultant votre documentation en ligne (lien : <i><a href="https://www.acontis.com/en/dcm.html" rel="nofollow noreferrer noopener" target="_blank">https://www.acontis.com/en/dcm.html</a></i>) , nous nous demandions s’il était possible de modifier les valeurs du DCM Controller (ControllerSetVal, nCtlGain etc…) lors de l’initialisation du master ou bien en cours de fonctionnement de la communication Ethercat ? Comment savoir si le DCM Controller Set Value est en mode Default ou Enhanced ? Nous n’avons pas trouvé d’information sur ce point dans la documentation bien que des PDO existent. </p>
<p> </p>
<p>J’ai également trouvé sur votre site un guide détaillant le fonctionnement du DC (lien : <i><a href="https://public.acontis.com/manuals/EC-Master/3.1/html/ec-master-class-a/dcm.html" rel="nofollow noreferrer noopener" target="_blank">https://public.acontis.com/manuals/EC-Master/3.1/html/ec-master-class-a/dcm.html</a></i>). Est-il possible de nous fournir une copie du projet de démonstration <b>EcMasterDemoDc</b> ? Nous ne l’avons pas trouvé dans les sources que vous nous avez transmis. </p>
<p> </p>
<p>Hormis les logs spécifiques au DCM, avez-vous des conseils ou des outils pour débugger le DC ?</p>
<p> </p>
<p>Nous reviendrons vers vous si d’autres questions se présentent à nous.</p>
<p> </p>
<p>Bonne journée.</p>
<p> </p>
<p><b>Romain GOBARD</b></p>
<p> </p>
</div>

Bonsoir,<div><br></div><div>vous pouvez utiliser le dcmlog comme dans notre Example EcMasterDemoDc. En suivant la colonne CtlErr avec un diagramme, vous pouvez voir si les erreurs sont dues à un jitter ou un drift.</div><div><br></div><div>vous pouvez changer les parametres DCM, mais normalement les parametres suivant n'ont pas besoin d'être ajustés:</div><div>
<dl>
<dt><br></dt>
<dt>EC_T_INT nCtlGain<a href="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv4N24EC_T_DCM_CONFIG_BUSSHIFT8nCtlGainE" rel="nofollow noreferrer noopener" target="_blank" title="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv4N24EC_T_DCM_CONFIG_BUSSHIFT8nCtlGainE"></a><br>
</dt>
<dd><p>[in] Proportional gain in ppt (part per thousand). Default is value 2. A value of 0 let the current setting unmodified.</p></dd>
</dl>
<dl>
<dt>
<span></span>EC_T_INT nCtlDriftErrorGain<a href="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv4N24EC_T_DCM_CONFIG_BUSSHIFT18nCtlDriftErrorGainE" rel="nofollow noreferrer noopener" target="_blank" title="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv4N24EC_T_DCM_CONFIG_BUSSHIFT18nCtlDriftErrorGainE"></a><br>
</dt>
<dd><p>[in] Multiplier for drift error. Default value is 3. A value of 0 let the current setting unmodified</p></dd>
</dl>
<dl>
<dt>
<span></span>EC_T_INT nMaxValidVal<a href="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv4N24EC_T_DCM_CONFIG_BUSSHIFT12nMaxValidValE" rel="nofollow noreferrer noopener" target="_blank" title="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv4N24EC_T_DCM_CONFIG_BUSSHIFT12nMaxValidValE"></a><br>
</dt>
<dd><p>[in] Error inputs above this value are considered invalid. If error input prediction is valid then the difference between the error input and the expected value is taken. Default value is 3000. A value of 0 let the current setting unmodified</p></dd>
</dl>
