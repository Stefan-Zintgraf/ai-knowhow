Hi Hans,<div><br></div><div>yes MasterShift under Vxworks is not supported out of the box, they need today some specific HW Layer depending on the timer HW (local APIC timer or 8254) they use for they EtherCAT cycle.</div><div><br></div><div>This is one restriction of MasterShift:</div><div>
<a href="https://software.acontis.com/Documents/AT1020_V1.3_EC-Master-Technical.pdf" title="https://software.acontis.com/Documents/AT1020_V1.3_EC-Master-Technical.pdf" rel="nofollow noreferrer noopener" target="_blank">https://software.acontis.com/Documents/AT1020_V1.3_EC-Master-Technical.pdf</a> Page 35</div><div><br></div><div>In V3.2, we extend the API with <span style="background-color: initial; color: rgb(88, 88, 86);">pfnAdjustCycleTime</span><span style="background-color: initial; color: rgb(88, 88, 86);">, to enable the customers to implement the time adjustment by themselves:</span>
</div><div><a href="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv427EC_T_DCM_CONFIG_MASTERSHIFT" title="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv427EC_T_DCM_CONFIG_MASTERSHIFT" rel="nofollow noreferrer noopener" target="_blank">https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv427EC_T_DCM_CONFIG_MASTERSHIFT</a></div><div><br></div><div>Unfortunately, we don't have an official overview but if the OS provide some nanosleep functions like Linux, the implementation is easy. They can ask WindRiver.</div><div><a href="https://pubs.opengroup.org/onlinepubs/007904975/functions/nanosleep.html" title="https://pubs.opengroup.org/onlinepubs/007904975/functions/nanosleep.html" rel="nofollow noreferrer noopener" target="_blank">https://pubs.opengroup.org/onlinepubs/007904975/functions/nanosleep.html</a></div><div><br></div><div>Today we have some unmaintained source code for 8254 support on QNX, RTOS-32, VxWorks and for LoAPIC on RTOS-32 and VxWorks.</div><div><br></div><div>Best Regards,<br><div data-signature="true" data-signature-id="2">
