### ARTICLE01_BODY
<div>
<div>Hi Takuya,</div>
<div><br></div>
<div>ecatWriteSlaveRegisterReq() is a non-blocking API and returns as soon as the command could be queued. EC_E_NOERROR is the expected return value disregarding any register accessibility.<br>
</div>
<div><br></div>
<div>Unfortunately EC_NOTIFY_SLAVE_REGISTER_TRANSFER doesn't contain the WKC information.</div>
<div><br></div>
<div>using ecatWriteSlaveRegister() should return EC_E_NOTREADY if WKC == 0.</div>
<div><br></div>
<div>Best Regards,</div>
<div>Cyril</div>
