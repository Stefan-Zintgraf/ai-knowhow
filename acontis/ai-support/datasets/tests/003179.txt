Inquery / API Specification

### ARTICLE01_BODY
Dear hiroshi-San,<div><br></div><div>Q1: When emCoeSdoDownload is called from within the job task this will lead to a deadlock.</div><div>The API will block the job task.</div><div><br></div><div>Q2: </div><div>emCoeSdoDownload will wait until the transfer is finished.</div><div>emCoeDownloadReq will return without waiting for the transfer to be finished.</div><div><br></div><div>Q3:</div><div>The Frame will be sent when emExecjob is executed.</div><div>At the same time, <span>emCoeSdoDownload is being executed. That is why </span><span>emCoeSdoDownload</span><span> </span><span>may not be called from within the JobTask's context because it needs </span><span>emExecjob to be executed.</span>
</div><div>
<span>When emExecJob is finished with the sending of the frame </span><span>emCoeSdoDownload will exits and return.</span>
