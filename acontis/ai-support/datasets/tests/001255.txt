<p>Hallo Support,</p>
<p> </p>
<p>wir verwenden in der Version 2.9 des EC Master Stack</p>
<p> </p>
<p>EC_T_MEMREQ_DESC stMemDescr;</p>
<p>EC_T_MEMPROV_DESC stProvDescr;</p>
<p> </p>
<p>Ab dem gelben Teil bekommen wir nun mit der Version RTOS-32 3.1.1.01 Fehlermeldungen</p>
<p> </p>
<p>…</p>
<p> </p>
<p>//!Register PDO memory provider in master stack</p>
<p>// setup the memory provider</p>
<p>stProvDescr.pvContext = (EC_T_PVOID)pstContext;</p>
<p>stProvDescr.pbyPDOutData = EC_NULL; // no fixed buffers</p>
<p>stProvDescr.dwPDOutDataLength = stMemDescr.dwPDOutSize;</p>
<p>stProvDescr.pbyPDInData = EC_NULL; // no fixed buffers</p>
<p>stProvDescr.dwPDInDataLength = stMemDescr.dwPDInSize;</p>
<p>stProvDescr.pfPDOutDataReadRequest = PDOutDataReadRequest; // callbacks for cyclic</p>
<p>stProvDescr.pfPDOutDataReadRelease = PDOutDataReadRelease; // PDO data transmit</p>
<p>stProvDescr.pfPDInDataWriteRequest = PDInDataWriteRequest; // callbacks for cyclic</p>
<p>stProvDescr.pfPDInDataWriteRelease = PDInDataWriteRelease; // PDO data receive</p>
<p>…</p>
<p> </p>
<p>Version RTOS-32 3.1.1.01 ?</p>
<p> </p>
<p><img style="max-width:100%;width:9.1875in;max-height:1.4479in;width:882px;max-height:139px;" src="/api/v1/ticket_attachment/1255/6800/24627?view=inline"></p>
<p> </p>
<p>EC_T_PFMEMREQ hat sich geändert.</p>
<p> </p>
<p>typedef EC_T_VOID (*EC_T_PFMEMREQ)(EC_T_PVOID pvContext, EC_T_DWORD dwTaskId, EC_T_PBYTE* ppbyPDData);</p>
<p> </p>
<p>Was bedeutet der neue Parameter dwTaskID ?</p>
<p>Was muss hier übergeben werden ?</p>
<p> </p>
<p>Danke.</p>

Hallo Herr Föll,<div><br></div><div>mit dwTaskID wird die Information für welche Zyklische Task der Speicher vom Master angefordert wird zur Applikation weitergegeben. Das ist für Applikationen wichtig die verschiedene EtherCAT Tasks mit unterschiedlichen Zykluszeiten betreiben.</div><div><br></div><div>Sie müssen nur ihren jetzigen Callback um dwTaskId erweitern und können die Variable dann ignorieren.</div><div><br></div><div>Mit freundlichen Grüßen,<br><div data-signature="true" data-signature-id="2">
