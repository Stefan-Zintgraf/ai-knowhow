Hi,<div><br></div><div>yes, the SDK Layer 5 &amp; 4 contains also a C++ wrapper. This wrapper is currently based on mixed code, which runs only on Windows.</div><div><br></div><div>If they want to use it on linux, they have to convert the wrapper to use "DllImport".</div><div>We use this already in our EC-Master Wrapper.</div><div><br></div><div>If they want to use Qt, they can convert the wrapper to be based on mono. This is another approach and very useful in combination with Qt. Some years ago we created already a small sample Qt based GUI which was based on our Layer 4. The sample code is out dated. If they are interested, I have to talk to Christoph, maybe we can upgrade the code.</div><div><br></div><div>Another solution might be to use our SDK like an executable, e.g. for generating ENI files with the EniBuilder.</div><div>In that case the do not need interaction with our C# code.</div><div><br></div><div>Best Regards,</div><div>Martin<br><div data-signature="true" data-signature-id="2">
