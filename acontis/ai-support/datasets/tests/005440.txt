### ARTICLE02_BODY
Hi Jim,<div> </div><div>You could use LD_LIBRARY_PATH to set the path in which the binary looks for the needed libraries. For example:</div><div>
<div> </div>
<div>LD_LIBRARY_PATH=./Release:/opt/Xenomai3/x86Cobalt/lib ./EcMasterDemo ….</div>
<div> </div>
<div>In the included example application the ./Release folder is the one containing the acontis libs.</div>
<div> </div>
<div>Since you are using Xenomai you should also include the path of the Xenomai libs (for example /opt/Xenomai3/x86Cobalt/lib). On Linux this is not necessary.</div>
<div> </div>
<div>You can also use the command line:</div>
<div> </div>
<div>export LD_LIBRARY_PATH=./Release:/opt/Xenomai3/x86Cobalt/lib</div>
<div> </div>
<div>This is equivalent to the one above but this path will be valid for all binaries, which may not be necessary.</div>
