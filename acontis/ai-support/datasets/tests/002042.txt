### ARTICLE00_SUBJECT
Potential issue in notification processor in example code

### ARTICLE00_BODY
<div>Dear Acontis Support Team,</div><div> </div><div>I have found a potential issue in the example code provided. Could you please confirm whether it's true or not?</div><div> </div><div>In Examples/Common/EcNotification.cpp, there is ecatNotify() function which is a callback to process notifications. In that function, there is a section that processes the mailbox related notifications:</div><div> </div><div>switch dwCode</div><div>case EC_NOTIFY_MBOXRCV<br>
</div><div>switch (pMbxTfer-&gt;eMbxTferType)</div><div>case eMbxTferType_COE_SDO_DOWNLOAD<br>
</div><div>case eMbxTferType_COE_SDO_UPLOAD</div><div> </div><div>In those two SDO DOWNLOAD/UPLOAD cases, if the transfer has an error, it logs a message. I believe the message creation is problematic.</div><div>
<ul>
<li>EcLogMsg(EC_LOG_LEVEL_ERROR, (pEcLogContext, EC_LOG_LEVEL_ERROR, ecatGetText(EC_TXT_COE_SDO_DNLD_ERROR), pMbxTfer-&gt;eTferStatus, pMbxTfer-&gt;dwErrorCode, ecatGetText(pMbxTfer-&gt;dwErrorCode)));<br>
<br>
</li>
<li>EcLogMsg(EC_LOG_LEVEL_ERROR, (pEcLogContext, EC_LOG_LEVEL_ERROR, ecatGetText(EC_TXT_COE_SDO_UPLD_ERROR), pMbxTfer-&gt;eTferStatus, pMbxTfer-&gt;dwErrorCode, ecatGetText(pMbxTfer-&gt;dwErrorCode)));<br>
</li>
</ul>
</div><div> </div><div> ecatGetText(EC_TXT_COE_SDO_DNLD_ERROR) gives you <i>"CoE - SDO download failure, EtherCAT address=%d - Index=0x%x SubIndex=0x%x CompleteAccess=%d, statVal=%d, errCode=0x%x (%s)"</i> which is passed on to snprintf() function.</div><div> </div><div>
<i>snprintf()</i> requires 7 parameters following the text to populate those % tokens. However, only 3 parameters are supplied.</div><div> </div><div>Best regards,</div><div>Piyamate</div>
