### ARTICLE01_BODY
Hi Kuanghan,<div><br></div><div>
<span>EC_NOTIFY_DCM_SYNC is generated every time DCM get InSync or OutOfSync. Yes the system time value of the reference clock is compared to an expected value. If the difference is bigger than the configured limit, it will become OuOfSync. After the difference stay below the configured limit for the configure duration, it becomes InSync again.</span><br>
</div><div><span><br></span></div><div><span>OutOfSync in OP is pointing to a unexpected jitter. If this jitter is OK for the application / slaves, you can increase the DCM limit.</span></div><div><span><br></span></div><div>Best Regards,</div><div>
