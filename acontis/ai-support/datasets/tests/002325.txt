<p>Hello,</p>
<p> </p>
<p>My name is Cristi and I am a colleague of Vlad. I will try to clarify our problem and simplify the actual question, in order not to get too deep into unnecessary details about the internals of your motion library.</p>
<p> </p>
<p>As Vlad mentioned earlier, we want to use the already implemented function block <b>MC_STOP_T</b> to ‘gracefully’ stop the motion in various situations (when a sensor is activated, for ex.). We already written the code, the function block gets executed when we needed and it works, its fine. The problem is that we didn’t entirely understand the <b>measurement unit</b> for the parameters of the function block. More precisely for the <b>Deceleration</b> and <b>Jerk</b> parameters. Your documentation states that the measurement units are <b>u/s^2</b> and <b>u/s^3</b> respectively, where <b>u</b> is “<i>increments per physical unit</i>”. Below I will detail the actual situation we have:</p>
<p> </p>
<p>The stop function is implemented as follows:</p>
<p> </p>
<p>static void MotionStop(T_RTOS_THREAD_PARAM* pRtosThreadParam, EC_T_RTOS_AXIS *pRtosAxis)</p>
<p>{</p>
<p>TRC("MotionStop");</p>
<p> </p>
<p>if(pRtosAxis &amp;&amp; !pRtosAxis-&gt;pFb-&gt;Stop.Execute)</p>
<p>{</p>
<p>pRtosAxis-&gt;pFb-&gt;Stop.Deceleration = pRtosAxis-&gt;m_StopAcc;</p>
<p>pRtosAxis-&gt;pFb-&gt;Stop.Jerk = pRtosAxis-&gt;m_StopJerk;</p>
<p>pRtosAxis-&gt;pFb-&gt;Stop.Execute = MC_TRUE;</p>
<p> </p>
<p>if (pRtosAxis-&gt;pdwDigOutputs)</p>
<p>*pRtosAxis-&gt;pdwDigOutputs = pRtosAxis-&gt;m_StopOutputs;</p>
<p>}</p>
<p>}</p>
<p> </p>
<p>The values <b>pRtosAxis</b><b>-&gt;m_StopAcc</b> and <b>pRtosAxis</b><b>-&gt;m_StopJerk </b>are set from our desktop application and can have different values for different scenarios of motion stopping. In our application, these values are set in <b>microns/s^2</b> and <b>microns/s^3</b>, respectively. A usual value for acceleration/deceleration is 10.000.000, for example. Also, we compute a calibration factor, from increments to microns. This factor is set in your motion library in <b>pAxis-&gt;dwIncPerMM</b>, <b>pAxis-&gt;dwCalcIncPerMM</b> (and possibly other variables) and we use it to convert from increments to microns and vice versa. A usual value for this factor is 40, for example. It can be positive or negative depending on the direction the axis motion vs the orientation of our coordinate system. The frequency of the RTOS loop is 1 millisecond.</p>
<p> </p>
<p>As I said before, the function block works, but we are not entirely capable of properly controlling the deceleration. So, <b>the question</b> is: what do we have to set for the deceleration parameter of the function block (<b>pRtosAxis</b><b>-&gt;pFb-&gt;Stop.Deceleration</b>), having the following data in our software:</p>
<p>- deceleration in microns/s^2 = 10.000.000</p>
<p>- increments per micron = 40/-40</p>
<p> </p>
<p>I hope I managed to explain the issue clearly.</p>
