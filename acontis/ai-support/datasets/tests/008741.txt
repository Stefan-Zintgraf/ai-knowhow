### ARTICLE00_BODY
<div style="color:#1f497d;">
<div style="color:#1f497d;">Dear,</div>
<div style="color:#1f497d;">I know that we will win the customer GENERTEC, And this customer have a question about repeat frame in twincat.</div>
<div style="color:#1f497d;"><br></div>
<div style="color:#1f497d;">They used the frame repeat support in twincat with beckhoff servo. But they find that this function only could implement with beckhoff servo, the twincat can't work with panasonic servo.</div>
<div style="color:#1f497d;">Do you know this function in twincat?</div>
<div style="color:#1f497d;"><img src="/api/v1/ticket_attachment/8741/49081/203479?view=inline" style="max-width:100%;"></div>
<div style="color:#1f497d;">So they want to checking, dose the EcMaster support this kind of function.</div>
<div style="color:#1f497d;"><br></div>
<div style="color:#1f497d;">I find the requirement from syntec before, and we could implement a demo following the step:</div>
<div style="color:#1f497d;">
<div style="color:#1f497d;">It is today possible by doing the following implementation:</div>
<div style="color:#1f497d;">- Determine the round trip time by using EcMasterDemoSyncSm or emSelfTestScan()</div>
<div style="color:#1f497d;">- Define a timeout value according the roundtrip time</div>
<div style="color:#1f497d;">- Use EC-Master in interupt mode like EcMasterDemoSyncSm</div>
<div style="color:#1f497d;">- Run an additonal monitoring task in parallel of the job task</div>
<div style="color:#1f497d;">- Just after eUsrJob_SendAllCycFrames, trigger the monitoring task</div>
<div style="color:#1f497d;">- The monitoring task call nanosleep for the previously defined timeout</div>
<div style="color:#1f497d;">- When the monitoring task wakes up, if the pvCycFrameReceivedEvent is not set, call eUsrJob_SendAllCycFrames from the monitoring task again to repeat the lost cyclic frame.</div>
<br>
</div>
<div style="color:#1f497d;">Dose the FrameRepeatSupport is same the step?</div>
<div style="color:#1f497d;"><br></div>
