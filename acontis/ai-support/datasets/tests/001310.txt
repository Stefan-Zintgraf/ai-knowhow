### ARTICLE00_SUBJECT
Question on error notification for LRW command

### ARTICLE00_BODY
<div>
<p>Hello,</p>
<p> </p>
<p>I’m currently working on an EtherCAT architecture using the EC-Master stack on QNX.</p>
<p>It contains just 1 master and 1 slave.</p>
<p>When transitionning to the SAFEOP or OP states, i receive a few error notifications named EC_NOTIFY_CYCCMD_WKC_ERROR (and after a few cycles, everything is alright).</p>
<p>From what i’ve understood in the documentation, it means that some slaves didn’t answer to the master command.</p>
<p>Looking at the EC_T_ERROR_NOTIFICATION_DESC, it seems that it happens for command LRW (WkcErrDesc.byCmd = 12) and that only 1 of the 3 slaves answered in time (WkcErrDesc.wWkcAct / WkcErrDesc.wWkcSet = 1/3), but i don’t understand where this « 3 » comes from.</p>
<p>It is indeed configured in the xml config file that i generated with TwinCAT :</p>
<p> </p>
<p><i> &lt;Cmd&gt;</i></p>
<p><i> &lt;State&gt;SAFEOP&lt;/State&gt;</i></p>
<p><i> &lt;State&gt;OP&lt;/State&gt;</i></p>
<p><i> &lt;Comment&gt;&lt;![CDATA[cyclic cmd]]&gt;&lt;/Comment&gt;</i></p>
<p><i> &lt;Cmd&gt;12&lt;/Cmd&gt;</i></p>
<p><i> &lt;Addr&gt;16777216&lt;/Addr&gt;</i></p>
<p><i> &lt;DataLength&gt;18&lt;/DataLength&gt;</i></p>
<p><i> <b>&lt;Cnt&gt;3&lt;/Cnt&gt;</b></i></p>
<p><i> &lt;InputOffs&gt;48&lt;/InputOffs&gt;</i></p>
<p><i> &lt;OutputOffs&gt;48&lt;/OutputOffs&gt;</i></p>
<p><i> &lt;/Cmd&gt;</i></p>
<p> </p>
<p>(And if i change it to 1, i get the « reverse » error after a few cycles i.e. 3 slaves answered instead of 1)</p>
<p> </p>
<p>Do you have any insight into where this number comes from and why this kind of error can happen ?</p>
<p>My slave is an ELMO Trombone drive. Please find the ESI file of the drive (ProductCode="#x00030924" RevisionNo="#x00010420") and my config attached.</p>
<p> </p>
<p>Thanks in advance.</p>

### ARTICLE01_BODY
Hi Thomas,<div><br></div><div>during the SO (<span>SAFEOP-&gt;OP</span><span>) transition it is possible that the slave doesn't process some cyclic frames. You should not modify the ENI file. Perhaps you can ignore these notification if the master state is not OP.</span>
</div><div>
<span>You can try to use </span><span>EC_IOCTL_SET_AUTO_ADJUST_CYCCMD_WKC_ENABLED and check if you still see the error. Using this IOCTL, the stack adjust the expected WKC according the state and presence of the slaves.</span>
</div><div><br></div><div>Best Regards,</div><div>Cyril<div><br></div>
