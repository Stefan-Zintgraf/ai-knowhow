CRC Error Generation with EC-Simulator

### ARTICLE03_BODY
Hi Jon,<div><br></div><div>the EC-Simulator does not contain CRC error simulation as it might be expected (sending frames with wrong CRC through topology), but it contains wrong error at port leading to frame loss. So an application can set slave error at port resulting in frame loss which behaves nearly the same way as CRC errors would do. It must also lead to process data missing at the slaves and master which I assume was what Auris wants to check.</div><div><br></div><div>Best regards,</div><div>Paul<br><div data-signature="true" data-signature-id="2"><div><br></div></div>
