### ARTICLE02_SUBJECT
How to use Slave-to-Slave function with Cable Redundancy

### ARTICLE02_BODY
Hi,<div><br></div><div>In-Cycle Slave-to-Slave copy will not work with cable redundancy! But default Slave-to-Slave Copy should work!</div><div>The default Copy costs you two cycles, in the first cycle the Master read the process data from the first slave and store it  and in the second cycle it writes it to the second slave!</div><div>You can configure this in EC-Engineer under the Slave to Slave tab: Select Default and map your Slave-to-Slave copies</div><div><br></div><div><br></div><div>
