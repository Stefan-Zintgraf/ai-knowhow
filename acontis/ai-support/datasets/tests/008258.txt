### ARTICLE00_BODY
<div>
<div>Hi Support Team,</div>
<div> </div>
<div>This is from Mitsubishi.</div>
<div> </div>
<div>For example, EL2889 is appended and all PDO is set to SM0, WKC error is occurred with the ENI.</div>
<div> </div>
<div>EL2889 has 2 SM of Type Outputs, and in default setting, Channel 1 - 8 is using SM0 and 9 - 16 is using SM1.</div>
<div>So, Edit Channel 9 - 16 to use SM0, and exporting ENI.</div>
<div>Mitsubishi run EC-Master application with this ENI, but WKC error is occurred.</div>
<div> </div>
<div>So, Mitsubishi find a wrong point.</div>
<div>After above setting, EC-Engineer shows that "enable" contents of SM1 is "0", this means SM1 is not used because PDO is 0 length.</div>
