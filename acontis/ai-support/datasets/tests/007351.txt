### ARTICLE00_SUBJECT
ENI File API calls

### ARTICLE00_BODY
<div>
<p>Hi James,</p>
<p> </p>
<p>I spoke with the developers today about the APIs you can use for the getting information about the slaves from the ENI file. After you call ecatConfigMaster() in V3.1 or ecatConfigNetwork() in V3.2 you have access to all these APIs. You can use ones like ecatGetCfgSlaveInfo(): <a href="https://public.acontis.com/manuals/EC-Master/3.1/html/ec-master-class-b/api.html#emgetcfgslaveinfo" rel="nofollow noreferrer noopener" target="_blank">https://public.acontis.com/manuals/EC-Master/3.1/html/ec-master-class-b/api.html#emgetcfgslaveinfo</a>.</p>
<p> </p>
<p>After this you can use the SuperSet ENI APIs to include/exclude slaves, then finally you can load the new configuration with ecatConfigLoad() and ecatConfigApply().</p>
