How to reduce changing EtherCAT Bus state from PRE-OP to SAFE-OP [ thread::vok76bIoMx6WkiTwt8SqGy0:: ]

### ARTICLE01_BODY
Happy new year!<div><br></div><div>There are several parameters that influence the mentioned 4-5 seconds.</div><div><br></div><div>Ajin can lower e.g. the value of the DC configure parameter <b>dwSettleTime </b><a href="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dc_api.html#_CPPv4N17EC_T_DC_CONFIGURE12dwSettleTimeE" title="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dc_api.html#_CPPv4N17EC_T_DC_CONFIGURE12dwSettleTimeE" rel="nofollow noreferrer noopener" target="_blank">https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dc_api.html#_CPPv4N17EC_T_DC_CONFIGURE12dwSettleTimeE</a> or <span style="color: rgba(0, 0, 0, 0.87);"><b>dwTotalBurstLength </b></span><a href="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dc_api.html#_CPPv4N17EC_T_DC_CONFIGURE18dwTotalBurstLengthE" title="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dc_api.html#_CPPv4N17EC_T_DC_CONFIGURE18dwTotalBurstLengthE" rel="nofollow noreferrer noopener" target="_blank">https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dc_api.html#_CPPv4N17EC_T_DC_CONFIGURE18dwTotalBurstLengthE</a> or increase <b><span style="color: rgba(0, 0, 0, 0.87);">dwBurstBulk</span><span> </span></b><a href="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dc_api.html#_CPPv4N17EC_T_DC_CONFIGURE11dwBurstBulkE" title="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dc_api.html#_CPPv4N17EC_T_DC_CONFIGURE11dwBurstBulkE" rel="nofollow noreferrer noopener" target="_blank">https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dc_api.html#_CPPv4N17EC_T_DC_CONFIGURE11dwBurstBulkE</a>.</div><div><br></div><div>Furthermore they can lower 

<b><span style="color:rgba(0, 0, 0, 0.87);">dwInSyncSettleTime</span> </b><span style="color: rgba(0, 0, 0, 0.87);">of the DCM configure call </span><a href="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv4N27EC_T_DCM_CONFIG_MASTERSHIFT18dwInSyncSettleTimeE" title="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv4N27EC_T_DCM_CONFIG_MASTERSHIFT18dwInSyncSettleTimeE" rel="nofollow noreferrer noopener" target="_blank">https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv4N27EC_T_DCM_CONFIG_MASTERSHIFT18dwInSyncSettleTimeE</a> or increase <span style="color: rgba(0, 0, 0, 0.87);"><b>dwInSyncLimit </b></span><a href="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv4N27EC_T_DCM_CONFIG_MASTERSHIFT13dwInSyncLimitE" title="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv4N27EC_T_DCM_CONFIG_MASTERSHIFT13dwInSyncLimitE" rel="nofollow noreferrer noopener" target="_blank">https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-a/dcm_api.html#_CPPv4N27EC_T_DCM_CONFIG_MASTERSHIFT13dwInSyncLimitE</a> to speed up the process.</div><div><br></div><div>But they have to find out for themselves which values are still valid for them. e.g. a too low settle time might lead to more in-sync out of sync transitions than wanted.</div><div><br></div><div>Best regards, </div><div>
