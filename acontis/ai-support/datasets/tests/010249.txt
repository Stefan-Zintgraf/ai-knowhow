### ARTICLE00_SUBJECT
Strange Data in PS/ fmmu Init part of ENI file

### ARTICLE00_BODY
<div>Hi Cyril and everyone,</div><div>I hope that you are well and that everything is fine for you. We discovered a strange thing in the ENI file generated by the tool. As you can see on the screenshot I did a diff with Winmerge on two ENI files. The left one is created using EC-Engineer and the right one is an ENI file created by the SDK Configuration Tool. I got rid of the tags that mark this file as encrypted as suggested by one of your developers. So when comparing the two files they are the same for 99% of the data. The part that is different is this fmmu stuff and the value in the Data tag. When we test with the left file all is generated properly and we can set and read input/output data. When we test with the file on the right side this doesn't work anymore, for the same slaves, same topology and all. Inputs and Outputs are not usable. Is this data also encrypted? Because we had the information from you that only one tag is different and some attributes where added in the header of the ENI file, so when we take that out it should work normally.</div><div>Thank you very much for your insights on this matter!</div><div>Have a nice weekend!</div><div>Best regards,</div><div>Rainer</div><div>
