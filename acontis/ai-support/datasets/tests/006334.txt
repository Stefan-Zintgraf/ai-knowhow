### ARTICLE01_SUBJECT
The fucntion's support of the EcMotion "MC_HOME_T"

### ARTICLE01_BODY
Hi Lishan,<div><br></div><div>
<div>MC_HOME_T implements this mode, yes, but the Homing mode (0x6060 = 6)  is very drive specific. Usually it has to be parameterized upfront. <span>Also Homing mode is just supported, if the drives are operated in PP mode (0x6060 = 1).</span>
</div>
<div><br></div>
<div>If you want to operate the drive in CSP or CSV mode, you have to implement homing on the application level by using the function blocks MoveVelocity and McStop.</div>
<div>For example.</div>
<div>- check if the axis is before or after the homing switch/position.</div>
<div>- start moving with a high velocity in the direction where the homing switch is located</div>
<div>- while moving, monitoring the (digital) input, if the moving position is reached</div>
<div>- if yes, stop the axis with McStop</div>
<div>- start moving with a low velocity into the other direction</div>
<div>- while moving, monitoring the (digital) input, if the moving position is reached</div>
<div>
<div>- if yes, stop the axis with McStop</div>- this might be repeated several times</div>
<div><br></div>
<div>Please note, that EcMasterDemoMotion is a free example the EcMotionControl.cpp is provided "as is".</div>
<div>There are no plans to enhance the functionality.</div>
