Question about EC-Master(Murata Machinery) [M031]

Regarding M030, if it is possible to transmit multiple frames within a single cycle, I believe it is necessary to assign the datagrams of the Slave devices for each frame.
Could you please let us know whether this assignment of datagrams is done automatically by EC-Master, or if the user must configure it manually?
Additionally, if it is the former, I would like to know how to obtain information about which frame each Slave's datagram is assigned to, as well as the number of frames sent within a single cycle. If it is the latter, could you please explain the method for assigning datagrams and the maximum number of frames that can be assigned?

Best regards,
Takuya Fujikawa
