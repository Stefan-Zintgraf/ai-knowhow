### ARTICLE01_BODY
<div>Hi,</div><div><br></div><div>Q: 

In what cases is the emBadConnectionsReset API used?</div><div>A: <span>It is recommended to call emBadConnectionsReset() on startup of EC-Master to ensure that all error counters of all slaves are in a defined state.</span>
</div><div>
<span>Q: </span><span>Are there any errors that cannot be cleared without using this API?</span>
</div><div><span>A: This API reset only the following counters in the slave:</span></div><div>
<div>* - Invalid Frame Counter (0x0300),</div>
<div> * - RX Error Counter (0x0301),</div>
<div> * - Lost Link Counter (0x0310)</div>
