Hi Martino,<div><br></div><div>4. It is possible that you get some WKC error during the PS transition. Because the cyclic frames are sent before the slave reach the state, if the slave firmware has some delay, it can happen.</div><div>5. Sync Manager watchdog error happen if the SyncSM Watchdog is active (default) and the slave didn't receive cyclic frames  for more than 100ms (default). Your Windows environment is not reliable for the slave currently. It is possible to disbale the Watchdog by setting it to 0 in the EC-Engineer.</div><div><br></div><div>Best Regards,</div><div>Cyril<br><div data-signature="true" data-signature-id="2">
