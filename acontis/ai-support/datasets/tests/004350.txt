### ARTICLE01_SUBJECT
Inquery /　cache memory operation

### ARTICLE01_BODY
Dear Sawada-san,<div><br></div><div>The x86 is cache coherent, that means that the DMA should not be explicitly flush, but filling it from different core can lead to incoherence on the processor side. For example using owner flags in shared memory between the the cores. I f you do such read/write access from your application, you can use <span>OsMemoryBarrier(); to flush the pipes before changing the owner flag.</span>
