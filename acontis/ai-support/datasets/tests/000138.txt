Hi Jon,<div><br></div><div>it is searched for first in current directory then it tries dlopen (this is to prevent accidently loading outdated libs from /usr/lib).</div><div>See EcOs.cpp:</div><div><br></div><div><div>/* search LinkLayer first in current working directory and then with ld library search path */</div></div><div>
<div data-signature="true" data-signature-id="2">
<div><br></div>
<div>So renaming the .so in current dir should make LD_LIBRARY_PATH work in this case.</div>
<div><br></div>
<div>As another deprecated solution EcOs.cpp can be changed and linked explicitely to the executeable.</div>
