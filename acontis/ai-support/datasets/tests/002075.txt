Dear EtherCAT Support

Question about EC-Engineer (FANUC)

I am trying to create an installer for selling EC-Engineer.
I would like to include the EC-Engineer driver in the installer. Is there a way to create an installer recommended by Acontis?

In the provided SDK, only "emllPcap.dll" exists in the Run folder. In order to use this, I think that Npcap needs to be additionally installed in WinPcap compatibility mode.
On the other hand, when i installed the evaluation version of EC-Engineer, "emllNdis.dll" is included in the installation folder. In addition, an "NDIS" folder will be created to contain EcatNdisSetup-x86_64Bit.msi. This is written in the manual of EC-Engineer.
Which dll file, which driver installation is recommended to include in the installation folder?
Moreover, are there any .msm or packages provided by Acontis to create an installer that includes the driver?

Best regards,
Takuya Fujikawa
