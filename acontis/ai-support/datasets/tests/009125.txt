Hi,<div><br></div><div>Requested Master State: This is the requested master state when switching to diagnosis mode. If you select init, the master will stop in init. If you select OP, the master will try to switch to OP immediatly.</div><div>Diagnosis Mode: Cycle Time: It is the cycle time which is used for diagnosis mode in EC-Engineer. So you can have a cycle time in ENI above which is a lot faster, and a different when switchting to diagnosis mode on Windows with EC-Engineer.</div><div>Diagnosis Mode: DCM: This is the DCM Mode. Off is default. But you can select different ones now to have DC with EC-Engineer.</div><div><br></div><div>Best regards,</div><div>Kai</div><div>
