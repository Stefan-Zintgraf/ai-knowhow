Dear EtherCAT Support

Question about EC-Engineer (FANUC)

A customer using FANUC software based on EC-Engineer has a problem that the Network Scan was not successful.
The customer tried disabling the antivirus software, and the Network Scan was successful. Therefore, the antivirus software is the cause of this problem.
The customer's company does not allow the antivirus software to be disabled all the time. The customer wants to configure the antivirus software so that EC-Engineer can communicate, and is asking FANUC about the settings.

The FAQ in the EC-Engineer manual states, "Try to exclude ethernet protocol type "0x88a4" from your firewall."

So here are my questions.

Q1.
Are there any network protocols other than ethernet protocol type "0x88a4" that EC-Engineer may use?
UDP, other protocols, etc.

Q2.
Has acontis experienced any effective configuration of anti-virus software other than the network firewall of the anti-virus software?
For example, settings to register EC-Engineer .exe files and EcatNdis.sys as allowed programs, etc.

Q3.
Does acontis have any documents that describe examples of antivirus software settings other than the EC-Engineer manual?

Q4.
Does acontis have any other advice for FANUC customers?

Best regards,
Takuya Fujikawa
