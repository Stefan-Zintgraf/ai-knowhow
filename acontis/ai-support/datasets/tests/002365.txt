Question about EC-Engineer + EC Simurator (FANUC)

About "EC-Simulator-HiL-V3.1-Windows-x86_64Bit-Eval.zip" provided on 1/11.
Please tell me how to use the EC-Engineer SDK and Simulator in combination.

I ran the command line with the EXI file created by the EC-Engineer SDK, but I get an OEM key error.
　|C:\Program Files\acontis_technologies\EC-Simulator-HiL-Windows-x86_64Bit\Bin\Windows\x64 >
　|"EcSimulatorHilDemo.exe -Ndis 192.168.1.200 1 -f EXI.xml -t 0 -v 3"
   |ERROR: Cannot configure EtherCAT network: ERROR loading encrypted ENI needs OEM key set (ecatSetOemKey) (0x9813000a))

I also tried adding SetOEMKey() and build it, but it doesn't contain the required files.
 >C:\Program Files\acontis_technologies\EC-Simulator-HiL-Windows-x86_64Bit\Workspace\WindowsVS2010\EcSimulatorHilDemo\EcSimulatorHilDemo.vcxproj
The properties of this project include the additional library directory "..\..\..\SDK\LIB\Windows\x86".
However, the installed folder only exists in "C:\Program Files\acontis_technologies\EC-Simulator-HiL-Windows-x86_64Bit\SDK\LIB\Windows\x64". "x86" doesn't exist.
Even if I change the additional library directory to "..\..\..\SDK\LIB\Windows\x64", build error occurs.

When I tried SiL before, I used the evaluation version of EC-Engineer. In this time, the evaluation version of EC-Engineer cannot be used because OEM is required for FANUC's EC-Master. I need to use the ENI & EXI file created by the EC-Engineer SDK.

Best regards,
Takuya Fujikawa

Hi Takuya,<div><br></div><div><b><u>Visual Studio</u></b></div><div><br></div><div>I think the SDK contains the required files. <span>In Visual Studio, don't modify project settings, but please select platform "x64" from within the IDE for </span><span>EC-Simulator HiL Windows x86_<b>64Bit</b> as you are running 64Bit, not 32Bit (it's the same project for both packages):</span>
</div><div><span><br></span></div><div>
<img style="max-width:100%;width: 647px;max-width: 100%;" src="/api/v1/ticket_attachment/2365/12484/48769?view=inline"><br>
</div><div><br></div><div>
<div>In Debug settings of your project, please add the installation bin folder with needed DLLs to the PATH environment variable:</div>
<div>
<br>
</div>
</div><div>
<img style="max-width:100%;width: 1000px;max-width: 100%;" src="/api/v1/ticket_attachment/2365/12484/48770?view=inline"><br>
</div><div><br></div><div><br></div><div><b><u>OEM-Key</u></b></div><div><b><u><br></u></b></div><div>
<div>If you don't have the OEM-key, please load the <b>same .ecc</b> file to an EC-Engineer without OEM protection to export the ENI/EXI so it contains the same settings, but without encryption.</div>
<div><br></div>
</div><div>
<span>- </span><b>HiL: </b><span>If you have the the OEM-key and you are using </span><b>HiL</b><span>, please call esSetOemKey before esConfigureNetwork.</span>
</div><div><span><br></span></div><div>- <b>SiL: </b><span>If you have the the OEM-key and you are using </span><b>SiL</b><span>, please set </span><span style=" color: rgb(51, 51, 51);">EC_T_LINK_PARMS_SIMULATOR::qwOemKey </span><span>given at pLinkParms of ecatInitMaster.</span>
</div><div><span><br></span></div><div>
