<div>
<p>Hi Cyril:</p>
<p> </p>
<p>I am getting on the average, reading/writing a single IO, or PDO, a time delay of 1.22 msecond.</p>
<p>I did investigate the issue on my side. I noticed the following calls are causing the 1 mescond above. To me I concluded the following 2-function causing the problem</p>
<p> </p>
<p>EC_T_DWORD RValue= emGetProcessDataBits( MasterIndex, EC_TRUE/*output data*/, Offset, pData, DataBitLength, 100);</p>
<p>EC_T_DWORD RValue= emSetProcessDataBits( MasterIndex, EC_TRUE/*Output Data*/, Offset, pData, DataBitLength,100/*TimeOUt*/);</p>
<p> </p>
<p>Below is the code I am using to read a single IO. Including timing.</p>
<p> </p>
<p>unsigned int</p>
<p>EtherCATAcontis::ReadOutProcessDataBits( unsigned char *pData, unsigned int Offset, unsigned int DataBitLength)</p>
<p>{</p>
<p>struct timeval Start;</p>
<p>struct timeval End;</p>
<p>gettimeofday( &amp;Start, NULL);</p>
<p>//printf(" EtherCATAcontis::ReadOutProcessDataBits: pData= %x Offset= %d, DataLength= %d", *pData, Offset, DataBitLength);</p>
<p>EC_T_DWORD RValue= emGetProcessDataBits( MasterIndex, EC_TRUE/*output data*/, Offset, pData, DataBitLength, 100);</p>
<p>gettimeofday( &amp;End, NULL);</p>
<p>std::cout &lt;&lt; "EtherCATAcontis::ReadOutProcessDataBits:" &lt;&lt; (End.tv_sec * 1000 + End.tv_usec/1000.) - (Start.tv_sec * 1000 + Start.tv_usec/1000.) &lt;&lt; std::endl;</p>
<p>return RValue;</p>
<p>}</p>
<p> </p>
<p>I am using the dynamic library, as well as raw socket.</p>
<p>Do you think I can get the static library, if it is available, to run the time performance and compare it with the Dynamic one?</p>
<p>Any feedback regarding this problem will help.</p>
<p> </p>
<p>Currently, I am switching to real time, instead of using raw socket, I do the same test to compare.</p>
<p> </p>
<p>Cheers.</p>
<p>-Abdulla</p>
