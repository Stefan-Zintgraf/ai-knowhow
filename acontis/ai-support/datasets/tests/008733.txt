### ARTICLE01_SUBJECT
Regarding Transition in "set sm2(outputs)"

### ARTICLE01_BODY
Hi,<div><br></div><div>1. <span>Why does EC-Engineer output SO as the transition for InitCmd "set sm2 (outoput)"?</span>
</div><div>--&gt; Because the device has no MCU and uses Device Emulation. This is read from the ESI file from the ConfigData. If the Device uses DeviceEmulation, this transition has to be SO</div><div><br></div><div>2. I think you have to talk to the vendor, to make sure this device needs DeviceEmulation or if they could patch the ESI file.</div><div><br></div><div>Best regards,</div><div>Kai Feifel</div><div>
