Hi Silvio,<div><br></div><div>the log file you sent me shows different issues. EC-Master generates some notifications:</div><div><br></div><div>[2025-07-29 14:41:30]  0000322345: Notify <b>EC_NOTIFY_FRAME_RESPONSE_ERROR</b>(No response error for cyclic frame IDX=0x19, CycFrameNum=0, TaskId=0)</div><div>-&gt; These notification are for diagnosis purpose: Perhaps there are some electro magnetic or wiring issues</div><div><br></div><div>[2025-07-29 14:54:54]  0001126301: Notify <b>EC_NOTIFY_CYCCMD_WKC_ERROR</b>(12, 0x10000000, 18, 48, 0, 0)</div><div>-&gt; These notification are for the application: In the current cycle the process data haven't been refresh as expected. Perhaps the application need to skip the cycle or ignore a part of it or should not take some decision</div><div><br></div><div><div>[2025-07-29 14:54:54]  0001126303: Notify <b>EC_NOTIFY_SLAVE_ERROR_STATUS_INFO</b>(1005, 0x0014, Fatal Sync Error (0x002C))</div></div><div>-&gt; These notification <span style="background-color: initial; color: rgb(88, 88, 86);">are for diagnosis purpose: Some slaves notify some errors</span>
</div><div><br></div><div>[2025-07-29 14:54:57]  0001128829: Notify <b>EC_NOTIFY_SB_MISMATCH</b>(0, 0, 255, 3001)</div><div>-&gt; These notification are for diagnosis purpose: The network doesn't match the configuration</div><div><br></div><div>I would start with the mismatch errors. If all slaves are present on the network, they should exist. The slave error should be checked in the manual or by the slave manufacturer under which condition this error is generated. <span style="background-color: initial; color: rgb(88, 88, 86);">EC_NOTIFY_CYCCMD_WKC_ERROR is a subsequent error.</span>
</div><div><br></div><div>EC_NOTIFY_FRAME_RESPONSE_ERROR can be tracked by checking the slave error counters. We have an API doing that:</div><div><a href="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-b/api.html?highlight=badconnection#embadconnectionsdetect" title="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-b/api.html?highlight=badconnection#embadconnectionsdetect" rel="nofollow noreferrer noopener" target="_blank">https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-b/api.html?highlight=badconnection#embadconnectionsdetect</a></div><div><br></div><div>In the field later, you need to collect these information somehow and present them. Perhaps you need to render the topology like EC-Engineer does to accelerate the diagnostic...</div><div><br></div><div>Best Regards,<br><div data-signature="true" data-signature-id="2">
