Hi,<div><br></div><div>no you cannot show these offsets. We always show the absolut values from the ENI. For easy slaves you can just calculate it by subtract the offset from the first variable with the actual variable of the slave.</div><div><br></div><div>You can also use Pinned Groups to pin a slave to a specific offset. So the slave will always start at this specific offset.</div><div><br></div><div>You can also use the process variable by name API from the EC-Master. This is the better way to get your process variable. Because what you want to do will not work for slaves with more SyncUnits. </div><div><br></div><div>Best regards,</div><div>Kai   <br><div data-signature="true" data-signature-id="2">
