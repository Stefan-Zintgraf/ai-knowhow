### ARTICLE01_BODY
Hi,<div><br></div><div>I try to explain the differences between the APIs:</div><div><br></div><div>
<div>
<span>EcSlaveDiagVariables.</span>ReadLatestValueFromBuffer </div>
<div>- Reads only a single value from internal cached buffer (will be filled asychronously from our internal timer)</div>
</div><div>
<div>
<span>EcSlaveDiagVariables.</span>ReadValues </div>
<div>- Reads 500 (see EcDefaultSettings.<span>AmountOfBufferEntries</span><span>) values (used in EC-Engineer to print the variables chart)</span>
</div>
</div><div>
<div>
<span>EcSlaveDiagVariables.</span>ReadValue </div>
<div>- Reads only a single value from the process image</div>
</div><div><br></div><div>We use "<span>EcSlaveDiagVariables.</span><span>ReadValues</span><span>" to create our variables chart in EC-Engineer. So I think yes, you can use it for your scope monitor, too:</span>
