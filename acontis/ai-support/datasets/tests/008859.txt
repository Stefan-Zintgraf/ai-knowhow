Hi Mike,<div><br></div><div>if you only receive <span>eRspErr_NO_RESPONSE, it will means real frame loss. Receiving </span><span>eRspErr_NO_RESPONSE and </span><span>eRspErr_UNEXPECTED means a timing issue.</span>
</div><div><br></div><div>*Frame loss:</div><div><br></div><div>This API can help you to find the location where the frames get lost</div><div><div><a href="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-b/api.html?highlight=badconnection#embadconnectionsdetect" title="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-b/api.html?highlight=badconnection#embadconnectionsdetect" rel="nofollow noreferrer noopener" target="_blank">https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-b/api.html?highlight=badconnection#embadconnectionsdetect</a></div></div><div><br></div><div>*Timing issue:</div><div><br></div><div>we have an integrated performance measurement in EC-Master:</div><div>
<a href="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-b/api_perfmeas.html?highlight=histog#api-perfmeas--page-root" title="https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-b/api_perfmeas.html?highlight=histog#api-perfmeas--page-root" rel="nofollow noreferrer noopener" target="_blank">https://public.acontis.com/manuals/EC-Master/3.2/html/ec-master-class-b/api_perfmeas.html?highlight=histog#api-perfmeas--page-root</a><br>
</div><div><br></div><div>You can test it by starting our EcMasterDemo with -perf 2 -sp and attached to it with EC-Engineer:</div><div><div><a href="https://public.acontis.com/manuals/EC-Engineer/3.9/html/diagnosis-mode.html#performance" title="https://public.acontis.com/manuals/EC-Engineer/3.9/html/diagnosis-mode.html#performance" rel="nofollow noreferrer noopener" target="_blank">https://public.acontis.com/manuals/EC-Engineer/3.9/html/diagnosis-mode.html#performance</a></div></div><div><br></div><div>Doing this, you can monitor the cycle it self and the offset in the cycle where <span style=" color: rgba(0, 0, 0, 0.87);">eUsrJob_</span><span style=" color: rgba(0, 0, 0, 0.87);">SendAllCyc</span><span style=" color: rgba(0, 0, 0, 0.87);">Frames is called.</span>
