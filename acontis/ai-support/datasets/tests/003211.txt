### ARTICLE00_BODY
<div dir="ltr">
<br>Hello,<br><br>We intialize EC Master using an ENI file and are wondering if it is possible to ignore a device on the bus.<br><br>Our goal is to use devices that are chained to a Beckhoff ET1100 device that is not flashed with any firmware.<br><br>The bus scan correctly shows the daisy chained devices, but we fail to enter cyclic OP.<br><br>Bus Scan:<br><br>ID..................: 0x00000001 <br>Bus Index...........: 0 <br>Bus AutoInc Address.: 0x0000 ( 0) <br>Bus Station Address.: 0x03ea (1002) <br>Bus Alias Address...: 0x0000 ( 0) <br>Vendor ID...........: 0xFFFFFFFF = Unknown <br>Product Code........: 0xFFFFFFFF = Unknown <br>Revision............: 0xFFFFFFFF Serial Number: -1 <br>ESC Type............: Beckhoff ET1100 (0x11) Revision: 0 Build: 3<br>Connection at Port A: yes (to 0x00010000) <br>Connection at Port D: no (to 0xFFFFFFFF) <br>Connection at Port B: yes (to 0x00000002) <br>Connection at Port C: no (to 0xFFFFFFFF) <br>Line Crossed........: no <br>Line Crossed Flags..: 0x0 <br><br>******************************************************************************<br><br>ID..................: 0x00000002 <br>Bus Index...........: 1 <br>Bus AutoInc Address.: 0xffff (65535) <br>Bus Station Address.: 0x03eb (1003) <br>Bus Alias Address...: 0x0000 ( 0) <br>...<br><br>What we tried:<br><br>1A: Disabled the Beckhoff ET1100 device in TcXaeShell. This seems to remove it from the ENI and we get: Scan bus mismatch for the first slave on bus.<br>1B: Only defined the chained devices with the same result as in 1A.<br>2A: Defined the Beckhoff ET1100 device as EJ1100 EtherCAT Coupler, disabled the vendor and device type checks (unchecked everything in the advanced EtherCAT settings), and set the Final State to INIT. We additionally modified the ENI the port if the chained device to B.<br> * This results in `Slave init command working counter error - Slave Term 6 (EJ1100): - EtherCAT address=1002 - Command: FPWR - Logical/Physical address: 0x12003ea, WKC act/set=0/1`<br>2B: After also modifiying the `InitCmds` of the ET1100 device, the EC master seems to hang on a state change:<br> Cannot start set master state to SAFEOP: ERROR: Time-out (0x98110010)<br> ecatSetMasterState() Error 0x98110010 in McSm state 'START' for requested state 'START' <br> ...<br> WLP.cpp:815] Writer 01.0f.26.8e.01.00.12.cf.01.00.00.00|0.0.2.3 not found.<br> No response on cyclic Ethernet frame <br><div> </div>
