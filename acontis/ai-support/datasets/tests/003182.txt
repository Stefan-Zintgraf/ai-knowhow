</div><div><span style="color:rgb(0, 0, 128);">dwBytesPerSecondMin: the lowest value of TX bytes/second recorded by the master since the start </span></div><div><span style="color:rgb(0, 0, 128);">dwBytesPerSecondMax: maximal value of TX bytes/second recorded by the master since the start</span></div><div><br></div><div>
<span style="color:rgb(0, 0, 128);">dwBytesPerCycleAct: actual value of TX bytes/cycle</span><br>
</div><div>
<span style="color:rgb(0, 0, 128);">dwBytesPerCycleMin: </span><span style="color:rgb(0, 0, 128);">the lowest value of TX bytes/cycle recorded by the master since the start</span><span style="color:rgb(0, 0, 128);"><br></span>
</div><div>
<span style="color:rgb(0, 0, 128);">dwBytesPerCycleMax: </span><span style="color:rgb(0, 0, 128);">maximal value of TX bytes/cycle recorded by the master since the start</span><span style="color:rgb(0, 0, 128);"><br></span>
