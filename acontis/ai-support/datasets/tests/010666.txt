<br>
</div><div dir="ltr">----------</div><div dir="ltr">【Identified Event】</div><div>When [Sync Unit Cycle] of [Sync Unit 0] is set to [/30], the calculation result of [User defined] is not the value obtained by dividing [Sync Unit Cycle (us)] by 30, but by 29. For example, if the [Sync Unit Cycle (us) is 1000, the result should be 33.33 but the result is 34.48.</div><div dir="ltr">
<br>
</div><div>【Expected behavior】</div><div>The calculation result of "User defined" is divided by 30. For example, if "Sync Unit Cycle (us)" is 1000, the result is 33.33.</div><div>Since the calculation result is correct, the other items do not change.</div><div dir="ltr">
<br>
</div><div>【Reproduction steps】</div><div>1. Add a slave with DC function.</div><div>2. Check "Overwrite Mode".</div><div>3. Check "Sync Unit</div><div>4. Check "Sync Unit0".</div><div>5. Check "Sync Unit Cycle</div><div>6. Select "/30" from the "Sync Unit Cycle" drop-down list</div><div dir="ltr">
<br>
</div><div>Result:</div><div>・Sync Unit Cycle" is unchecked.</div><div>・The drop-down list of "Sync Unit Cycle" is changed to "/100".</div><div>・User defined" is checked.</div><div>・User defined" is calculated as "Sync Unit Cycle (us)" divided by 29.</div><div dir="ltr">----------</div><div>
<p><span><br>
</span></p>

<p>Please add [/30] and fix this issue to calculate correctly, if selecting [/30] at the case that Sync Cycle Unit = 1000, Result is 33.33us.</p>
