### ARTICLE00_SUBJECT
An error is occurred at ecatInitMaster() (QNo.101)

### ARTICLE00_BODY
<div>Hi Support Team,</div><div> </div><div>I received the question from Mitsubishi (commission No. 40627).</div><div> </div><div>===</div><div>■Problem</div><div>We have received the V3.2.2.03 release of EC-Master, but it does not start with an error during initialization.</div><div> </div><div>■Questions about cause and specification</div><div>After debugging, we found that the direct cause was due to OsMalloc() being executed (*) before OsInit().</div><div>We understood the specification that OsLayer assumes that OsInit() is executed first, but is my understanding wrong?</div><div> </div><div>
<div>* This occurs when pParms-&gt;pOsParms is set valid in the argument of EC_T_DWORD CEcMasterInterface::InitMaster() in \AtEthercat.cpp which is called within ecatInitMaster().</div>
</div><div> </div><div>■Supplementation</div><div>This time, OsInit() and OSMalloc() are implemented by us based on OS-Layer-DevKit.</div><div>The Developer manual states “Initializes the Os Layer itself, i.e. time functions or memory allocation. Therefore, OsInit() performs memory allocation (initialization necessary to execute OsMalloc()).</div><div>Therefore, if OsMalloc() is executed prior to OsInit(), an error will be returned and the caller, eatInitMaster(), will terminate with an error.</div><div>===</div><div> </div><div>Please check the question and answer it…</div><div> </div><div>Best regards,</div><div>Yuichi</div><div> </div><div>～プロフェッショナル集団を目指すＳＳＶグループ～</div><div>
