Hi,<div><br></div><div>the Lost frames are read from the EC-Master object dictianary. On startup it is normal, that there are some lost frames. After the master is in op you can clear the counters. Then there should not be any more lost frames. But on Windows it is possible that there will appear more lost frames. </div><div>A frame is lost when it does not come back in time. Maybe it is not lost, just missed. This is caused by timing and it will be to late.</div><div><br></div><div>Best regards,</div><div>Kai<br><div data-signature="true" data-signature-id="2">
