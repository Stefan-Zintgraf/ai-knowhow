Dear EtherCAT Support

Question about EC-Master (FANUC) Q6

About input data validity and slave status at the moment of disconnection:

Q6-(1).
   The case the following events occur immediately after the master sends the output data.
   (event 1) The LAN on the Master side is disconnected.
   (event 2) The LAN in front of Slave3 is disconnected.
   (event 3) Slave3 becomes a failure (INIT). The slave is connected.

   In the each events, does OsWaitForEvent (RxEvent, CYCLE_TIME) time out?

Q6-(2)
   In the each events,  is the master's input data  updated after OsWaitForEvent (RxEvent) call?

Q6-(3)
   If (2) is yes, what kind of data is it?
   If not, is it still the same old data from before slave become ​failer?

Q6-(4)
   If (1) does not time out (before executing ecatExecJob (MasterTimer))
   -Does emIsSlavePresent () return TRUE?
   -Does GetSlaveState () return Op?

Q6-(5)
   If the timeout does not occur in (1), is it possible to check whether the input data of the master is old data? (Before executing ecatExecJob (MasterTimer))

Q6-(6)
   After executing ecatExecJob(MasterTimer).
   Does emIsSlavePresent () return FALSE?
   Does GetSlaveState () return INIT or PRE-OPE?

Best regards,
Takuya Fujikawa

<div>Q6-(2)</div>
<div>   In the each events,  is the master's input data  updated after OsWaitForEvent (RxEvent) call?</div>
<div>[CER] It depends on the usage of EC_IOCTL_SET_IGNORE_INPUTS_ON_WKC_ERROR, EC_IOCTL_SET_ZERO_INPUTS_ON_WKC_ZERO, EC_IOCTL_SET_ZERO_INPUTS_ON_WKC_ERROR.</div>
<div>By default the Input are only modified if a frame is returned and the WKC is not higher as the expected one.</div>
