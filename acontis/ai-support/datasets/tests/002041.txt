<p>Hello,<br>
<br> We have been using EC-Engineer to configure a Beckhoff EL6751 CAN module for RAW CAN frames and has been working just fine. Now we wish to improve our solution by allowing the Baud rate of a module to be configured dynamically without creating a new ENI xml for each change.<br>
